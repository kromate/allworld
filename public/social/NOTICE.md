# Allworld social preview artwork

Original project artwork, Apache-2.0, 2026 Allworld contributors.
The street and location mark derives from src/ui/BrandMark.vue, original Apache-2.0 project code.
The map lines are a schematic brand illustration, not geographical data or a gameplay screenshot.
No photographs, real people's likenesses, private records or third-party artwork are used.

Editable sources: scripts/seo/allworld-og.svg and scripts/seo/favicon.svg.
Allworld uses Arial with a sans-serif fallback for the rasterized copy. This distributes raster artwork, not font software.
Rasterized with Sharp 0.35.4 using its SVG renderer. PNG output is 1200x630 for the card,
48x48 for favicon.png and 180x180 for apple-touch-icon.png. Sharp is authoring tooling only;
no runtime dependency was added. Existing project asset notices remain in force.
