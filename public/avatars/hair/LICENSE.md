# Authored hair assets

`afro01.pack.gz`, `braid01.pack.gz`, and `long01.pack.gz` contain adapted mesh and texture data from the MakeHuman **system assets** pack. MakeHuman lists each of these three hair assets as **CC0** in its [system asset inventory](https://static.makehumancommunity.org/assets/assetpacks/makehuman_system_assets.html). The source `.obj` and `.mhclo` files also carry the MakeHuman September 2020 CC0 notice. See the [MakeHuman asset licence](https://github.com/makehumancommunity/makehuman/blob/master/LICENSE.ASSETS.md).

Source archive: `https://files.makehumancommunity.org/asset_packs/makehuman_system_assets/makehuman_system_assets_cc0.zip` (mirror of the inventory's system pack). The source files below were extracted from that archive and checked before conversion. The packs contain the OBJ's triangulated position/UV mesh, a reduced mesh made offline with the MIT-licensed meshoptimizer simplifier, and a 512 px, grey-tinted version of its diffuse PNG preserving alpha. No MakeHuman application code is included.
